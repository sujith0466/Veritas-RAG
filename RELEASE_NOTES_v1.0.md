# Release Notes: RAGuard AI v1.0

We are thrilled to announce the Release Candidate 1 for RAGuard AI v1.0. This release brings enterprise-grade RAG capabilities to the open-source community.

## Key Highlights
- **Hybrid Retrieval**: RRF-based fusion of sparse and dense vectors.
- **Hallucination Prevention**: Strict confidence thresholds.
- **Multi-Tenant Security**: Tenant isolation at the database and vector levels.
