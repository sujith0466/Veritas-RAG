# Tracked Files to Untrack

## Overview
This document identifies files that are currently tracked by Git but violate enterprise repository hygiene guidelines. These files consist of local developer configurations, generated static analysis reports, and dynamic operational test outputs.

## Files Identified
1. `docker-compose.override.yml`
   - **Reason:** Local infrastructure orchestration overrides should never be shared globally across the team as they contain host-specific ports, volumes, or experimental tweaks.
2. `ruff_output.json`
   - **Reason:** Static analysis cache/report generated locally by Ruff. Should not pollute version control.
3. `docs/Archive/retrieval_results.json`
   - **Reason:** Dynamic test output generated by retrieval tests/scripts.

## Remediation Strategy
These files will not be deleted from the disk to preserve local developer context, but they will be removed from Git's tracking index using the `git rm --cached` command. Once untracked, the updated `.gitignore` will ensure they are never committed again.
