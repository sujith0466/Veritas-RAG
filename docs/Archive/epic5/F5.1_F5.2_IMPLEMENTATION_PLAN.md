**Status:** ⏳ PENDING APPROVAL

This plan maps the frozen architecture and the Enterprise Refinements (from the Final Architecture Review) into a concrete execution sequence.

## 1. Database & Alembic Migration

**New Files:**
- `backend/database/migrations/versions/<timestamp>_f5_1_f5_2_folders.py`

**Purpose:** 
Create the `folders` table with the Adjacency List structure, materialized `depth` and `path`, and necessary indexes and constraints.

**Key Operations:**
- Create table `folders` extending `BaseModel` (id, created_at, updated_at, is_deleted, deleted_at).
- Columns: `workspace_id` (UUID, FK, CASCADE), `parent_id` (UUID, FK, SET NULL), `name` (String 255), `slug` (String 255), `depth` (SmallInt), `path` (Text), `document_count` (Integer), `deleted_by_user_id` (UUID, FK, SET NULL), `created_by_user_id` (UUID, FK, SET NULL), `version` (Integer).
- DB CHECK constraints: `depth <= 10`, `document_count >= 0`.
- Indexes: `ix_folders_workspace_root`, `ix_folders_parent`, `ux_folders_slug_in_parent` (unique partial index where `is_deleted=FALSE`), `ix_folders_path` (GIST), `ix_folders_deleted_at`.

**Dependencies:** None
**Implementation Order:** 1

## 3. Repository Layer

**New Files:**
- `backend/repositories/folder_repository.py`

**Modified Files:**
- `backend/repositories/document_repository.py` (for the Document Visibility Contract)

**Purpose:**
Implement data access, CTEs for descendants, and enforce tenant isolation.

**Key Operations:**
- `FolderRepository`:
  - `get_by_id_in_workspace(id, ws_id)`
  - `get_children(parent_id, ws_id, cursor, limit)`
  - `get_root_folders(ws_id, cursor, limit)`
  - `search_folders(ws_id, query, cursor, limit, parent_id=None)`
  - `exists_name_in_parent(ws_id, parent_id, normalized_name, exclude_id=None)`
  - `get_subtree_ids(folder_id, ws_id)` → Recursive CTE with explicit `workspace_id` guards in both anchor and recursive terms.
  - `get_ancestors(folder_id, ws_id)` → iterative parse of `path`.
- `DocumentRepository`:
  - Update base query to enforce `LEFT JOIN folders` where `folders.is_deleted = FALSE` OR `documents.folder_id IS NULL`.

**Dependencies:** SQLAlchemy Models
**Implementation Order:** 3

## 4. Service Layer

**New Files:**
- `backend/services/folder_service.py`

**Purpose:**
Implement core business logic, optimistic locking, duplicate detection, and caching.

**Key Operations:**
- `create_folder(workspace_id, actor_id, name, parent_id)`
  - Depth validation, circular ref check, rate limits, workspace cap.
- `rename_folder(workspace_id, actor_id, folder_id, new_name, expected_version)`
  - No-op check, DB optimistic lock, cache invalidation.
- `soft_delete_folder(workspace_id, actor_id, folder_id, expected_version)`
  - Phase 1 synchronous root mark, Celery enqueue, lock check.
- `restore_folder(workspace_id, actor_id, folder_id)`
  - Parent status validation, Phase 1 sync restore, Celery enqueue.
- `get_folder_stats(workspace_id, folder_id)`
  - Aggregation for descendants and documents.

**Dependencies:** Repository Layer, RBAC
**Implementation Order:** 5

**Key Operations:**
