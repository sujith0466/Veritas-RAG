# Completion Report: Epic 5 (Document Intelligence) - F5.5 and F5.6

## Features Implemented
1. **F5.5 Document Archival & Restoration**
    - `POST /api/v1/workspaces/{workspace_id}/documents/{document_id}/archive` endpoint implemented.
    - `POST /api/v1/workspaces/{workspace_id}/documents/{document_id}/restore` endpoint implemented.
    - Synchronous DB status updates with async Celery dispatch (`remove_archived_document_vectors_job`, `restore_archived_document_vectors_job`).
    - Handled cascading vector deletion/re-embedding on Qdrant via the `VectorStorageService`.
    - Integrated with RBAC (`permissions.require("document:archive")`, `permissions.require("document:restore")`).
    
2. **F5.6 Document Versioning**
    - Built version-aware routing in DocumentService (`get_by_id_with_versions`).
    - Implemented `/versions` list API.
    - Implemented POST `/versions` to upload new versions (triggers new OCR/embedding pipeline).
    - Implemented POST `/versions/{version_id}/rollback` to revert the document to a previous physical state.
    - Reused underlying object storage blobs for rollback without duplicating storage.
    - Implemented async job `cleanup_old_version_vectors_job` to gracefully remove orphaned Qdrant vectors after a new version finishes ingestion.
