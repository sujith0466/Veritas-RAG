## 2. Divergence Remediation Tasks (Top Priority)

Before or alongside the core feature implementation, the following codebase divergences identified in the Architecture Review must be fixed:

### 2.1 Remove Hardcoded Embedding Provider
- **File:** `backend/tasks/listeners.py`
- **Action:** In `handle_chunking_completed`, remove `provider="local", model_name="all-MiniLM-L6-v2"`. Instead, resolve the provider/model from `app_settings.embeddings` or the tenant's workspace settings (if available). Pass the resolved provider/model down into `process_embedding_batch_task`.

### 2.2 Refactor Qdrant Collection Naming Strategy
- **File:** `backend/vector_db/client.py` and `backend/modules/vector/services/vector_service.py`
- **Action:** Refactor `AsyncQdrantClient.collection_name()` to generate names based on dimension (e.g., `raguard_knowledge_1536`) instead of tenant (e.g., `raguard_{tenant_id}`).
- **Verification:** Ensure `VectorPointDTO` payload isolation by `tenant_id` remains the primary isolation layer in Qdrant.

### 2.3 Correct `acquire_lock()` Usage
- **File:** `backend/document/services/processing_job_service.py` (and any other occurrences)
- **Action:** Update the call signature from `acquire_lock(self.redis, lock_key, timeout_sec=60, wait_sec=2)` to match the infrastructure definition in `backend/cache/locks.py`: `acquire_lock(lock_key, timeout=60, acquire_timeout=2)`. Remove the `self.redis` argument.
- **Action:** Apply the correct `acquire_lock` signature inside the new Celery workers for F6.4 and F6.5.

### 2.4 Dedicated `indexing` Queue Separation
- **File:** `backend/tasks/celery_app.py`
- **Action:** Add `"indexing"` to the Celery `task_queues` list and define its routing.
- **Action:** Update the routing table to route `sync_vectors_to_qdrant_task` to `"indexing"` instead of `"ingestion"`.

## 3. Database Changes & Alembic Migrations

### 3.1 Schema Modifications
**Target Table:** `embedding_jobs` (ORM Model: `EmbeddingJob`)
- **Add Column:** `step_metrics` (JSONB, nullable=True) for storing estimated cost, fallback flags, and token usage metadata.
- **Add Column:** `cancellation_reason` (Text, nullable=True) to track why a job was aborted.
- **Add Column:** `fallback_provider` (Text, nullable=True) to track the actual provider used if the primary failed.

**Target Table:** `vector_index_metadata` (ORM Model: `VectorIndexMetadata`)
- No structural changes required (already contains `UNIQUE(tenant_id, document_version_id, collection_name)`). However, ensure the `status` enum validation supports `"SKIPPED"` for archived/superseded versions.

### 3.2 Alembic Migration Generation
- Generate migration: `alembic revision --autogenerate -m "Add tracking fields to embedding_jobs"`
- Ensure `step_metrics` uses the Postgres JSONB dialect.

## 4. Component Modifications

### 4.1 Models
- **`backend/modules/embedding/models/embedding_job.py`:** Add `step_metrics`, `cancellation_reason`, and `fallback_provider` attributes to the SQLAlchemy model.

### 4.2 Repositories
- **`EmbeddingRepository` (`backend/modules/embedding/repositories/embedding_repository.py`):**
  - Add logic in `update_job_progress` to update the new `step_metrics` fields (e.g., append fallback state and calculate cost).
  - Add method `update_job_cancellation(job_id, tenant_id, reason)`.
- **`VectorMetadataRepository`:**
  - Update `get_or_create_metadata` to use the dimension-based collection name (e.g., `raguard_knowledge_1536`).

### 4.3 Services
- **`EmbeddingManager` (`backend/modules/embedding/providers/manager.py`):**
  - Implement the provider fallback chain: `Primary` → `Secondary` → `Tertiary` inside `vectorize_batch()`. Catch timeouts/API errors and transition gracefully, returning the `provider_metadata` of the successful fallback.
- **`EmbeddingService` (`backend/modules/embedding/services/embedding_service.py`):**
  - Enforce provider rate limits using `RateLimiter.check_limit()` before hitting `manager.vectorize_batch()`.
  - Calculate token cost (`tokens_consumed * cost_per_token`) and store it in `step_metrics`.
  - Verify document archive status before processing a batch.
- **`VectorStorageService` (`backend/modules/vector/services/vector_service.py`):**
  - Enhance `sync_document_vectors()` to handle `VECTOR_UPSERT_BATCH_SIZE=500` and stream the points to Qdrant.
  - Implement `cleanup_old_versions_vectors(document_id, new_version_id, tenant_id)`.
  - Add a post-upsert consistency check (compare upserted count to Qdrant's reported delta).

### 4.4 Workers & Celery Queues
- **`CeleryEmbeddingWorker` (`backend/modules/embedding/workers/embedding_worker.py`):**
  - Wrap batch execution in `async with acquire_lock(f"embedding:job:{job_id}", timeout=600, acquire_timeout=5)`.
  - Handle `RateLimitExceeded` by calling `self.retry(countdown=60)`.
- **`sync_vectors_to_qdrant_task` (`backend/modules/vector/workers/tasks.py`):**
  - Wrap execution in `async with acquire_lock(f"vector:sync:{document_version_id}", timeout=300, acquire_timeout=5)`.
  - Update `celery_app.task` decorator to use `queue="indexing"`.

## 5. Enterprise Infrastructure & Controls

### 5.1 Event Flow
- Ensure `EmbeddingService` fires `EMBEDDING_COMPLETED` with accurate token and cost metadata.
- Ensure `VectorStorageService` fires `VECTORS_INDEXED` with `tenant_id` and collection name.
- Verify `backend/tasks/listeners.py` connects `CHUNKING_COMPLETED` → `process_embedding_batch_task` and `EMBEDDING_COMPLETED` → `sync_vectors_to_qdrant_task`.

### 5.2 Distributed Locking
- Ensure F6.4 locks at the job level: `f"embedding:job:{job_id}"` (600s TTL).
- Ensure F6.5 locks at the version level: `f"vector:sync:{document_version_id}"` (300s TTL).

### 5.3 Retry Strategy & Rate Limiting
- **F6.4 (Embedding):** Jittered backoff for timeouts; 60s fixed wait for `RateLimitExceeded`. Max retries = 3.
- **F6.5 (Vector Sync):** Exponential backoff (`2^retries * 5s`). Max retries = 5.
- Both fail to DLQ via state transition (`status = "FAILED"`) and emit failure events.

### 5.4 Token Tracking & Cost Estimation
- Define cost configuration in `app_settings` for OpenAI ($0.00013/1K) and Cohere ($0.00010/1K).
- Ensure `EmbeddingService` tracks cumulative cost in `job.step_metrics["estimated_cost_usd"]`.

### 5.5 Multi-Tenant Payload Isolation
- Explicitly verify `VectorPointDTO.payload` has `tenant_id`.
- Ensure all Qdrant `search()` and `delete()` calls enforce the `Filter(must=[FieldCondition(key="tenant_id", value=tenant_id)])`.
