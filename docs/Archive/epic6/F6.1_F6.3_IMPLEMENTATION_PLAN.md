## F6.1 Phase 4 — Service Layer

### Objective
Create `ProcessingJobService` to encapsulate all job lifecycle logic.

### Files

#### `[NEW]` `backend/document/services/processing_job_service.py`
**Purpose:** Domain service orchestrating the full `ProcessingJob` lifecycle.  
**Class:** `ProcessingJobService`  
**Methods:**
- `create_job(document_id, version_id, batch_id, priority, tenant_id, session) -> ProcessingJob`
  - Generates `idempotency_key = SHA-256(f"{document_id}:{version_id}:job")`
  - Creates `ProcessingJobAuditLog` entry: `JOB_CREATED`
  - Emits `PROCESSING_JOB_CREATED` event via `EventDispatcher`
- `enqueue_job(job_id, tenant_id, session) -> None`
  - Sets `job.status = QUEUED`, `job.scheduled_at = now()`
  - Writes Redis idempotency key: `raguard:{tenant_id}:job:{job_id}:idempotency` (TTL 24h)
  - Appends audit: `JOB_QUEUED`
  - Emits `PROCESSING_JOB_QUEUED`
- `claim_job(job_id, worker_id, tenant_id, session) -> ProcessingJob`
  - Acquires Redis distributed lock: `raguard:{tenant_id}:job:{job_id}:lock` (SET NX PX 600000)
  - Sets `job.status = CLAIMED`, `claimed_at = now()`, `claimed_by_worker = worker_id`
  - Appends audit: `JOB_CLAIMED`
- `start_step(job_id, step_name, worker_id, session) -> ProcessingJobStep`
  - Creates `ProcessingJobStep` record with `status=RUNNING`, `started_at=now()`
  - Updates `job.current_step = step_name`
  - Appends audit: `STEP_STARTED`
- `complete_step(job_id, step_name, duration_ms, session) -> None`
  - Updates `ProcessingJobStep.status = COMPLETED`, `duration_ms`, `completed_at`
  - Appends audit: `STEP_COMPLETED`
  - Emits `PROCESSING_JOB_STEP_COMPLETED`
- `fail_step(job_id, step_name, error_code, error_msg, severity, session) -> None`
  - Updates `ProcessingJobStep.status = FAILED`
  - If RECOVERABLE: increments `job.retry_count`, schedules retry via `self.retry()`
  - If FATAL: calls `move_to_dlq()`
  - Appends audit: `STEP_FAILED`
- `complete_job(job_id, session) -> None`
  - Sets `job.status = COMPLETED`, `completed_at = now()`
  - Releases Redis lock
  - Appends audit: `JOB_COMPLETED`
  - Emits `PROCESSING_JOB_COMPLETED`
- `fail_job(job_id, error_code, error_msg, session) -> None`
  - Sets `job.status = FAILED`, `error_code`, `error_message`
  - Releases Redis lock
  - If `retry_count < max_retries`: schedule retry (emit `PROCESSING_JOB_RETRY_SCHEDULED`)
  - Else: `move_to_dlq()`
  - Appends audit: `JOB_FAILED`
- `move_to_dlq(job_id, reason, session) -> None`
  - Sets `job.status = DLQ`, `dlq_reason`, `dlq_at = now()`
  - Publishes to `ingestion.dlq` Celery queue
  - Releases Redis lock
  - Appends audit: `JOB_MOVED_TO_DLQ`
  - Emits `PROCESSING_JOB_MOVED_TO_DLQ`
- `cancel_job(job_id, cancelled_by_user_id, tenant_id, session) -> None`
  - Sets Redis cancel signal: `raguard:{tenant_id}:job:{job_id}:cancel_signal` (TTL 300s)
  - Sets `job.status = CANCELLATION_REQUESTED`
  - Appends audit: `JOB_CANCELLATION_REQUESTED`
- `confirm_cancellation(job_id, session) -> None`
  - Sets `job.status = CANCELLED`, `cancelled_at = now()`
  - Releases Redis lock
  - Emits `PROCESSING_JOB_CANCELLED`
- `resume_job(job_id, tenant_id, session) -> ProcessingJob`
  - Reads last completed `ProcessingJobStep` to determine `resume_from_step`
  - Sets `job.resume_from_step`, `job.status = QUEUED`
  - Re-enqueues Celery task
  - Appends audit: `JOB_RESUMED`
  - Emits `PROCESSING_JOB_RESUMED`
- `extend_lock(job_id, tenant_id) -> None`
  - Extends Redis lock TTL by 600s (heartbeat refresh, called every 30s by worker)
- `check_cancel_signal(job_id, tenant_id) -> bool`
  - Returns True if cancel signal key exists in Redis
- `escalate_stale_priority_jobs() -> int`
  - Anti-starvation: queries `get_pending_for_escalation(priority=0, age_hours=4)` and upgrades to priority=1
  - Returns count of escalated jobs

### Files

#### `[NEW]` `backend/document/workers/job_maintenance.py`
**Purpose:** Celery Beat maintenance tasks for queue health.  
**Tasks:**
- `stale_job_monitor()` — Decorated `@celery_app.task(name="processing_job.stale_monitor")`
  - Calls `JobRepository.get_stale_claimed_jobs(threshold_minutes=15)`
  - For each stale job: releases Redis lock, resets `status=QUEUED`, `claimed_by_worker=None`
  - Logs recovered jobs count
- `priority_escalation_task()` — Decorated `@celery_app.task(name="processing_job.priority_escalation")`
  - Calls `ProcessingJobService.escalate_stale_priority_jobs()`
  - Logs escalation count
- `dlq_archive_task()` — Decorated `@celery_app.task(name="processing_job.dlq_archive")`
  - Queries jobs with `status=DLQ AND dlq_at < NOW() - INTERVAL '7 days'`
  - Archives each to S3: `raguard/{tenant_id}/dlq/{job_id}.json`
  - Sets `is_deleted=True` on archived records (soft-archive)
