# F8.8 Citation Extraction from Stream

## 1. Overview
The objective of F8.8 is to extract and stream citations progressively as they are generated by the LLM. This provides a highly responsive UI where reference popovers become active immediately upon the citation marker appearing in the text, rather than appearing all at once at the end.

## 2. Current Architecture Limitations
In `StreamingGroundedGenerationService`, the `CitationExtractor.extract(full_text, safe_chunks)` method is invoked only after the LLM stream loop completes. This violates the progressive streaming requirement.

## 3. Proposed Architecture

### 3.1 Component Modifications
*   **`StreamingGroundedGenerationService` (Generation Module):**
    *   Introduce a streaming regex buffer that scans text deltas for citation markers (e.g., `[1]`, `[2]`).
    *   When a new marker is matched, intercept it and immediately invoke `CitationExtractor.extract_single(marker, safe_chunks)`.
    *   Populate `StreamingGenerationChunkDTO.citations_delta` with the newly resolved `CitationDTO`.
*   **`CitationExtractor` (Generation Module):**
    *   Maintain a `seen_citations` set per request to deduplicate extractions. If `[1]` is used twice, the second occurrence is ignored for extraction to preserve ordering and prevent duplicate events.
*   **`ChatOrchestrator` (Chat Module):**
    *   If `chunk.citations_delta` is non-empty, iterate over it and emit an `SSEMessageDTO(event="citation", data=citation.json())`.

### 3.2 Sequence Diagram
```text
Client            Orchestrator          GenService           CitationExtractor
  |                    |                     |                       |
  |--- stream request->|                     |                       |
  |                    |--- generate_stream->|                       |
  |                    |                     |<--delta "Paris [1]"---| (LLM)
  |                    |                     |---extract_single()--->|
  |                    |                     |<--CitationDTO---------|
  |                    |<-- chunk + cit_delta|                       |
  |<-- event: chunk ---|                     |                       |
  |<-- event: citation-|                     |                       |
```

### 3.3 Consistency Guarantee
The `CitationExtractor` will maintain the state of extracted citations for the lifecycle of the request. Upon stream completion, it performs a final validation pass. The ordered array of extracted `CitationDTO`s will be appended exactly to the DB via `ChatMessageCreateDTO(citations=final_citations)`, guaranteeing zero drift between what the client received progressively and what is persisted.
