# F8.7 Reliability Score Extraction from Stream

## 1. Overview
The objective of F8.7 is to incrementally calculate and emit a Reliability Score while the LLM is actively streaming, rather than waiting until stream completion. This improves perceived latency and allows the client UI to immediately reflect confidence levels of the generated response.

## 2. Current Architecture Limitations
Currently, `StreamingGroundedGenerationService` waits for the complete `full_text` to be generated before yielding the final citations and grounding status. The orchestrator then picks up the `reliability_score` (often mocked as 1.0 or calculated post-hoc) in the final chunk. This creates a latency spike at the end of long generations.

## 3. Proposed Architecture

### 3.1 Component Modifications
*   **`StreamingGroundedGenerationService` (Generation Module):**
    *   Introduce an internal sentence buffer during the `async for delta in llm_provider.generate_stream()` loop.
    *   Every time a sentence boundary is detected (`.`, `?`, `!`), invoke the `ReliabilityEngine.evaluate_incremental(sentence, evidence)` in a non-blocking `asyncio.create_task`.
    *   The `StreamingGenerationChunkDTO` will be updated to include an optional `reliability_score_update` float field.
*   **`ReliabilityEngine` (Reliability Module):**
    *   Expose an `evaluate_incremental()` method using a sliding window of context and the local evidence.
    *   Combine the sentence-level scores using an Exponential Moving Average (EMA) to maintain a stable, running score that smoothly updates.
*   **`ChatOrchestrator` (Chat Module):**
    *   Detect chunks containing `reliability_score_update`.
    *   Map them to a new `SSEMessageDTO(event="reliability_score", data={"score": x.xx})` and yield immediately.

### 3.2 Data Flow
1. **Client** opens stream.
2. **AIWrapperService** routes to **StreamingGroundedGenerationService**.
3. **LLMProvider** yields token `delta`.
4. **StreamingGroundedGenerationService** detects a sentence boundary.
5. **ReliabilityEngine** evaluates the sentence asynchronously against `safe_chunks`.
6. **StreamingGroundedGenerationService** yields a chunk with `reliability_score_update=0.92`.
7. **ChatOrchestrator** yields `event: reliability_score\ndata: {"score": 0.92}`.

### 3.3 State Consistency
To guarantee the final score matches the stored score (no duplicates/drifts), the final chunk's `reliability_score` will be the definitive value persisted in the `QueryAnalyticsRecord` and `ChatMessageCreateDTO`. The client will treat the final `chunk.wrapper_metadata["reliability_score"]` as the absolute truth, overwriting any incremental state.
