# Epic 8 Batch 3 Implementation Plan: F8.7–F8.9

## 1. Exact Implementation Order

1.  **Phase 1: Foundation & Observability**
    *   Add feature flags (`ENABLE_STREAMING_RELIABILITY`, `ENABLE_STREAMING_CITATIONS`, `ENABLE_AI_POLICY_ENGINE`).
    *   Add Prometheus metrics for reliability, citations, policy violations, PII redactions, and blocked prompts.
    *   Update `SSEMessageDTO` in `backend/api/v1/schemas/sse.py` to support `reliability_score` (versioned) and `citation` events, as well as `POLICY_VIOLATION` error codes.

2.  **Phase 2: AI Policy Enforcement Middleware (F8.9)**
    *   Create DTOs for policy resolution (Tenant/Workspace overrides).
    *   Implement `PolicyEngine` to merge and cache policies in Redis.
    *   Implement `AIPolicyMiddleware` and Evaluators (TokenLimit, PromptInjection, BlockedTopic, PIIRedaction) in `backend/modules/security/middleware/ai_policy_middleware.py`.
    *   Integrate `AIPolicyMiddleware` into `AIWrapperService.stream_request` before hybrid retrieval.
    *   Update `ChatOrchestrator` to catch and yield `POLICY_VIOLATION` SSE errors.

3.  **Phase 3: Progressive Citation Extraction (F8.8)**
    *   Update `CitationExtractor` to support `extract_single` with deduplication and deterministic citation IDs.
    *   Modify `StreamingGroundedGenerationService` to scan for citation markers using a progressive regex buffer.
    *   Yield `citations_delta` immediately on marker match.
    *   Update `ChatOrchestrator` to emit `citation` SSE events iteratively.

4.  **Phase 4: Reliability Score Extraction (F8.7)**
    *   Update `ReliabilityEngine` to support `evaluate_incremental`.
    *   Modify `StreamingGroundedGenerationService` to detect sentence boundaries and dispatch background scoring tasks.
    *   Implement configurable scoring update interval (via feature flags/settings).
    *   Yield `reliability_score_update` metadata on chunks.
    *   Update `ChatOrchestrator` to emit `reliability_score` SSE events iteratively and preserve the final absolute score.

## 3. Detailed Implementation Tasks

### 3.1 Foundation
1.  **Add Feature Flags:** Modify `FeatureFlags` class to include `enable_streaming_reliability`, `enable_streaming_citations`, `enable_ai_policy_engine`. Default to False.
2.  **Add Metrics:** Define Prometheus counters `raguard_policy_violations_total`, `raguard_pii_redactions_total`, `raguard_sse_citations_emitted_total`, `raguard_sse_reliability_updates_total`.

### 3.2 AI Policy Enforcement (F8.9)
1.  **Create Policy DTOs:** Define `WorkspacePolicyDTO` and `TenantPolicyDTO` with fields for `max_tokens`, `blocked_topics`, `redact_pii`, `block_jailbreaks`.
2.  **Implement PolicyEngine:** Build a class that fetches tenant & workspace policies, merges them (workspace overrides tenant where permitted, otherwise strict wins), and caches the serialized result in Redis with a 5-minute TTL.
3.  **Implement AIPolicyMiddleware:**
    *   Takes `AIWrapperRequest` and merged policy.
    *   Runs `TokenLimitEvaluator` (checks `request.query` size).
    *   Runs `PromptInjectionEvaluator` (calls `PromptGuard`).
    *   Runs `BlockedTopicEvaluator` (calls LLMProvider with `use_lite_model=True` for fast classification).
    *   Runs `PIIRedactionEvaluator` (calls `DLPEngine.redact()`).
4.  **Integrate Middleware:** In `AIWrapperService.stream_request`, execute middleware before `namespace_resolver.resolve()`. If `PolicyViolationError` is raised, catch in `ChatOrchestrator`, log via `ComplianceAuditor`, and yield `SSEMessageDTO.error(code="POLICY_VIOLATION")`.

### 3.3 Citation Extraction (F8.8)
1.  **Enhance CitationExtractor:** Add `extract_single(marker, context, safe_chunks)`. Use a `seen_markers: set` to skip duplicates. Assign deterministic `Citation ID`s (e.g., `hash(document_id + excerpt)`).
2.  **Streaming Regex Buffer:** In `StreamingGroundedGenerationService`, accumulate `delta` into a `window_buffer`. Use `re.search(r'\[\d+\]')` to find markers.
3.  **Immediate Yielding:** Upon match, call `extract_single()`. If valid, clear the matched portion from the buffer, append the `CitationDTO` to `citations_delta` of the next yielded `StreamingGenerationChunkDTO`.
4.  **Orchestrator Emission:** In `ChatOrchestrator`, if `chunk.citations_delta` has items, emit `SSEMessageDTO(event="citation")` iteratively.

### 3.4 Reliability Score Extraction (F8.7)
1.  **Enhance ReliabilityEngine:** Implement `evaluate_incremental(sentence, evidence)` returning a float score.
2.  **Sentence Boundary Detection:** In `StreamingGroundedGenerationService`, check `window_buffer` for `. `, `? `, `! `.
3.  **Async Evaluation:** On boundary, dispatch `asyncio.create_task(ReliabilityEngine.evaluate_incremental)`. Do NOT await it inline. Attach a callback to queue the result.
4.  **Configurable Interval:** Check `settings.features.reliability_update_interval` (e.g. emit every 2 sentences).
5.  **Versioned Events & Orchestration:** When the async task finishes, yield `StreamingGenerationChunkDTO` with `wrapper_metadata={"reliability_score_update": val, "reliability_version": seq}`. `ChatOrchestrator` emits `SSEMessageDTO(event="reliability_score")`.

## 6. Database Impact
*   **Models:** No model changes required.
*   **Migrations:** None.
*   **Reuse:** Policies will be read from existing JSON payload settings on Workspace/Tenant tables. `QueryAnalyticsRecord` natively supports blocking statuses.

## 7. Event Flow
1. **Incoming Request:** `ChatOrchestrator` receives query.
2. **Policy Middleware:** `AIPolicyMiddleware` fetches merged policy, redacts PII, blocks violations.
3. **Retrieval:** `RetrievalOrchestrator` executes vector search.
4. **Generation:** `StreamingGroundedGenerationService` requests LLM stream.
5. **Progressive Extractions:**
    *   **Citation Extraction:** Marker matched -> `CitationDTO` yielded.
    *   **Reliability Extraction:** Sentence matched -> Async score calculation -> Score yielded.
6. **Streaming:** `ChatOrchestrator` intercepts deltas, formatting them as `SSEMessageDTO` and pushing to client.
7. **Persistence:** Complete query, final citations, and final absolute score persisted to Database.

## 8. Error Handling
*   **Policy Violation:** Halt execution immediately. `ComplianceAuditor` logs. `ChatOrchestrator` yields `POLICY_VIOLATION` SSE error.
*   **Blocked Topic:** Sub-category of Policy Violation. Fast LLM classifier throws error. Same handling as above.
*   **PII Detection:** No error thrown. Transparently mutates `query` string and logs `PII_REDACTED`.
*   **Reliability Timeout/Failure:** Caught silently inside the async task callback. The incremental score is skipped. Generation continues unaffected.
*   **Citation Extraction Failure:** Log warning, skip citation emission. Final post-stream validation pass will attempt recovery.
*   **Streaming Failure:** Standard `STREAM_TIMEOUT` or `INTERNAL_ERROR` handled by F8.5 mechanisms.

## 9. Performance Considerations
*   **Async Execution:** Reliability scoring must be fire-and-forget `asyncio.create_task` to prevent holding up the token stream.
*   **Buffering:** String matching on a sliding window prevents memory bloat for large generations.
*   **Throttling:** Reliability scores are throttled by `reliability_update_interval` to prevent UI thrashing.
*   **Redis Caching:** Merged hierarchical policies are cached with a 5-minute TTL to remove DB overhead on every stream request.

## 10. Security
*   **Tenant/Workspace Isolation:** Policy Engine explicitly requires both Tenant and Workspace UUIDs to ensure no cross-contamination of settings.
*   **Prompt Injection:** `PromptGuard` execution before retrieval protects the vector index from poisoned contexts.
*   **PII Masking:** Guaranteed execution via `DLPEngine` before the query leaves the backend.
*   **Audit Logging:** All redactions and violations hit the `ComplianceAuditor` for SOC2/Enterprise logging.

## 11. Testing Plan
*   **Unit Tests:** Test `PolicyEngine` merging logic. Test `CitationExtractor` deduplication. Test `AIPolicyMiddleware` chain.
*   **Integration Tests:** End-to-end policy override resolution with Redis.
*   **Streaming Tests:** Mock LLM to yield citations slowly, assert exact count and order of `SSEMessageDTO(event="citation")`.
*   **Policy Tests:** Submit known prompt injections and blocked topics; assert `POLICY_VIOLATION`.
*   **Security Tests:** Submit raw PII; assert it is redacted in retrieval logs and LLM inputs.
*   **Regression Tests:** Run existing full suite to ensure standard chat flows don't break.

## 12. Rollback Strategy
1. Disable feature flags (`ENABLE_STREAMING_RELIABILITY=false`, `ENABLE_STREAMING_CITATIONS=false`, `ENABLE_AI_POLICY_ENGINE=false`).
2. The code natively falls back to post-stream citation and post-stream reliability scoring.
3. If structural breaking issues arise, perform a standard `git revert` of the Batch 3 PR. Data structures (DB) are unchanged, guaranteeing zero data-loss on rollback.
